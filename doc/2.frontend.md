# 🎨 프론트엔드 기획안 (React + Vite)

> 로컬 전용 MVP. 컴포넌트 재사용 + 인터랙션 풍부한 화면 흐름에 집중.

---

## 1. 🎯 목표

- **5초 안에 끝나는 입력** 흐름을 매끄러운 SPA로 구현
- 사진 중심의 **타임라인 UI**
- 추후 PWA / 모바일 확장이 자연스러운 구조

## 2. 🧩 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 프레임워크 | **React 18** | 컴포넌트 재사용 / 인터랙션 처리 용이 |

| 라우팅 | **React Router v6** | 표준 |
| 서버 상태 | **TanStack Query** | 캐싱 / 재시도 / 로딩 상태 자동화 |
| 클라이언트 상태 | **useState / useReducer** | (Zustand 등 전역 상태는 필요 시 추가) |
| HTTP | **fetch** 또는 **axios** | 가벼움 |
| 폼 | (필요 시 react-hook-form) | MVP는 useState로도 충분 |

## 4. 🗺️ 라우팅 / 화면

| 경로 | 페이지 | 설명 |
| --- | --- | --- |
| `/` | HomePage | 큰 CTA + 최근 기록 3개 |
| `/recommend` | RecommendPage | 4단계 슬라이드 + 결과 |
| `/logs/new` | LogFormPage | 사진/장소/⭐/메모 |
| `/logs/:id` | LogDetailPage | 상세 / 수정 / 삭제 |
| `/timeline` | TimelinePage | 월별 카드 그리드 |

### 4.1 홈 `/`

- 상단 인사말 + 큰 버튼: **"오늘 데이트 추천받기"**
- 하단: 최근 데이트 기록 3개 (`LogCard` 가로 스크롤)
- 푸터: `TabBar` (홈 / 추천 / 기록 / 타임라인)

### 4.2 추천 `/recommend`

```text
useReducer로 4단계 상태 관리
  state: { step: 1~4, answers: { state, mood, activity, budget } }
  action: NEXT, PREV, SET_ANSWER, SUBMIT
```

| Step | 질문 | 버튼 |
| --- | --- | --- |
| 1 | 오늘 컨디션? | 😊 / 😐 / 😵 |
| 2 | 어떤 분위기? | 🧘 / 🎉 / 🎯 |
| 3 | 활동성? | 🚶 / 🎡 |
| 4 | 예산? | 💸 / 💳 / 💰 |

- 버튼 클릭 → `SET_ANSWER` + `NEXT`
- step 4 완료 시 `useMutation`으로 `POST /api/recommend`
- 결과는 `<CourseCard />`로 표시
- "다시 추천" → 같은 입력 유지하고 mutation 재실행

### 4.3 기록 작성 `/logs/new`

- `<PhotoUpload />` — `<input type="file" accept="image/*" capture>` + 클라이언트 리사이즈(최대 1280px)
- 장소명 input (자유 입력)
- `<StarRating />` ⭐ 1~5
- 메모 (선택, 1줄)
- 저장 시 `FormData`로 `POST /api/logs` (multipart)

### 4.4 타임라인 `/timeline`

- TanStack Query로 `?year&month` 호출, 캐시
- 월별 헤더 + `<LogCard />` 그리드 (2열)
- 카드 클릭 → `/logs/:id`

### 4.5 상세 `/logs/:id`

- 사진 풀사이즈
- 날짜 / 장소 / ⭐ / 메모
- [수정] [삭제] 버튼 (낙관적 업데이트)

## 5. 🎨 디자인 원칙

- **모바일 우선** (max-width 480px 가정, Tailwind `sm:` 최소)
- 큰 터치 영역 (`min-h-14`, 약 56px)
- 이모지 = 1차 시각 언어
- 색상 팔레트 (Tailwind config 확장)
  - Primary: `#FF7AA2` (코랄 핑크)
  - Accent: `#7AC7FF` (라이트 블루)
  - Background: `#FFF7F9`
- 폰트: Pretendard 권장 (CDN)
- 컴포넌트: 카드 / 큰 버튼 / 이모지 칩

### 재사용 컴포넌트 예시

```tsx
// EmojiButton.tsx
type Props = { emoji: string; label: string; selected?: boolean; onClick: () => void };
export function EmojiButton({ emoji, label, selected, onClick }: Props) {
  return (
    <button
      onClick={onClick}
      aria-label={label}
      className={`flex flex-col items-center justify-center rounded-2xl
        min-h-24 min-w-24 text-4xl transition
        ${selected ? "bg-primary/20 ring-2 ring-primary" : "bg-white"}`}
    >
      <span>{emoji}</span>
      <span className="mt-1 text-xs text-gray-600">{label}</span>
    </button>
  );
}
```

## 6. 🔌 API 연동

### 6.1 클라이언트

```ts
// api/client.ts
const BASE = import.meta.env.VITE_API_BASE ?? "http://localhost:8000";

export async function api<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await fetch(`${BASE}${path}`, {
    headers: { "Content-Type": "application/json", ...(init?.headers ?? {}) },
    ...init,
  });
  if (!res.ok) throw new Error(`${res.status} ${res.statusText}`);
  return res.json();
}
```

### 6.2 화면 ↔ 엔드포인트

| 화면 | 호출 |
| --- | --- |
| 홈 (최근 기록) | `GET /api/logs?limit=3` |
| 추천 결과 | `POST /api/recommend` |
| 기록 저장 | `POST /api/logs` (multipart) |
| 타임라인 | `GET /api/timeline?year&month` |
| 상세 | `GET /api/logs/{id}` |
| 수정/삭제 | `PATCH/DELETE /api/logs/{id}` |

### 6.3 CORS

- 백엔드(`http://localhost:8000`)와 프론트(`http://localhost:5173`) 포트가 다르므로 FastAPI에 `CORSMiddleware` 추가
  - `allow_origins=["http://localhost:5173"]`

## 7. 📱 UX 디테일

- 추천 4단계는 **이전 버튼**으로 되돌아가기 가능 (브라우저 back과 별개로 step 상태 유지)
- 결과 화면 "다시 추천" → 같은 입력으로 mutation 재호출
- 사진 업로드: 클라이언트에서 **canvas 리사이즈 → blob**으로 업로드 (최대 1280px)
- 만족도 별 클릭 시 **햅틱**: `navigator.vibrate?.(10)`
- 빈 상태(empty state) 컴포넌트: "아직 기록이 없어요. 첫 데이트를 추천받아볼까요?"
- 로딩 / 에러는 TanStack Query의 `isLoading` / `isError`로 일관 처리

## 9. ⚙️ 실행

```bash
# 1) 생성
npm create vite@latest frontend -- --template react-ts
cd frontend

# 2) 의존성
npm install
npm install react-router-dom @tanstack/react-query
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# 3) 개발 서버
npm run dev
# → http://localhost:5173
```
