# 🛠️ 백엔드 기획안 (FastAPI)

> 로컬 전용 MVP. 가볍고 단순하게. 외부 인프라 의존 최소화.

---

## 1. 🎯 목표

- 커플 데이트 추천 / 기록 / 타임라인을 위한 **최소한의 REST API** 제공
- **로컬 단일 실행** (`uvicorn main:app`) — DB·스토리지·서버 모두 한 머신
- 추천 로직은 **단순 룰 + 최근 기록 필터링** 수준에서 시작

---

## 2. 🧩 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 언어 | Python 3.11+ | 단순 / 빠른 개발 |
| 웹 프레임워크 | FastAPI | 자동 문서화, 타입 친화 |
| ASGI 서버 | Uvicorn | 가볍고 표준 |
| DB | SQLite | 파일 1개, 설치 불필요 |
| ORM | SQLModel | SQLAlchemy + Pydantic 통합 |
| 마이그레이션 | (생략) `create_all` | MVP라 alembic 미도입 |
| 파일 저장 | 로컬 디스크 (`./storage/photos`) | 외부 스토리지 불필요 |
| 검증 / 직렬화 | Pydantic v2 | FastAPI 내장 |
| 의존성 관리 | `uv` 또는 `pip + requirements.txt` | 가벼움 |
| 테스트 | pytest + httpx | (선택) |

## 5. 🌐 API 설계 (REST)

> 모든 응답은 JSON. 로컬용이라 인증은 닉네임 기반 단순 토큰(또는 생략).

### 5.1 추천

#### `POST /api/recommend`

**요청**

```json
{
  "state": "tired",        // good | normal | tired
  "mood": "calm",          // calm | excited | focused
  "activity": "low",       // low | high
  "budget": "mid"          // low | mid | high
}
```

**응답**

```json
{
  "course": [
    { "step": 1, "type": "cafe",   "name": "조용한 브런치 카페" },
    { "step": 2, "type": "walk",   "name": "한강 산책 코스" },
    { "step": 3, "type": "dessert","name": "디저트 카페" }
  ],
  "reason": "피곤+조용 → 카페 중심 코스"
}
```

### 5.2 데이트 기록

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| `POST` | `/api/logs` | 데이트 기록 생성 (사진 업로드 포함, multipart) |
| `GET` | `/api/logs` | 기록 목록 (날짜순) |
| `GET` | `/api/logs/{id}` | 단건 조회 |
| `PATCH` | `/api/logs/{id}` | 만족도 / 메모 수정 |
| `DELETE` | `/api/logs/{id}` | 삭제 |

### 5.3 타임라인

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| `GET` | `/api/timeline?year=2026&month=4` | 월별 그룹핑된 기록 |

### 5.4 커플 / 사용자

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| `POST` | `/api/users` | 닉네임으로 사용자 생성 |
| `POST` | `/api/couples` | 커플 페어링 |
| `GET` | `/api/me` | 현재 세션 사용자 |

### 5.5 정적 파일

- `GET /photos/{filename}` — 업로드된 사진 서빙 (`StaticFiles` 마운트)

### 5.6 CORS

프론트(`http://localhost:5173`, Vite)와 백엔드(`http://localhost:8000`, FastAPI)가 다른 포트에서 실행되므로 **CORS 미들웨어 필수**.

```python
# app/main.py
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

> 운영에서는 `allow_origins`를 실제 도메인으로 제한할 것. `["*"]` + `allow_credentials=True` 조합은 브라우저가 거부하므로 금지.

## 6. 🧠 추천 로직 (services/recommender.py)

**입력 → 태그 매핑 → 코스 풀 필터링 → 최근 기록 제외 → 셔플**

### 6.1 룰 테이블 (예시)

| 상태 | 분위기 | 활동성 | 추천 코스 타입 |
| --- | --- | --- | --- |
| tired | calm | low | 카페 → 산책 → 디저트 |
| good | excited | high | 액티비티 → 식사 → 야경 |
| normal | focused | low | 전시 → 식사 → 카페 |

### 6.2 최근 기록 기반 필터

- 최근 **N회(=5)** 안에서 사용된 `course_type` 조합은 우선순위 ↓
- 만족도 평균이 높은 타입은 가중치 ↑

### 6.3 코스 풀

- `app/data/courses.json`에 시드 등록 (장소 무관, "흐름" 단위)
- 예: `{ "id": 1, "type": "cafe", "name": "조용한 브런치 카페", "tags": ["calm","low","mid"] }`

## 8. 📂 파일 업로드 정책

- 한 기록당 사진 1장
- 최대 5MB, jpg/png/webp 허용
- 저장명: `{couple_id}_{date_log_id}_{uuid8}.{ext}`
- 경로: `./storage/photos/`
- 응답에는 `/photos/{filename}` 형태의 상대 URL 반환
