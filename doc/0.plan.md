# 💑 커플 데이트 추천 & 기록 웹앱 MVP 기획안

## 1. 📌 서비스 개요

### 서비스 한 줄 정의

> 매일 몇 번의 선택만으로 오늘 데이트 코스를 만들어주고, 우리의 데이트를 자동으로 기록해주는 커플 앱

---

## 2. 🎯 문제 정의 (Pain Point)

장기 연애 커플의 반복되는 문제:

- "오늘 뭐하지?" 고민 반복
- 항상 비슷한 데이트 (카페 → 밥 → 끝)
- 예전에 뭐 했는지 기억 안 남
- 좋은 데이트 경험이 쌓이지 않음

---

## 3. 💡 해결 방향 (Solution)

- 간단한 선택(3~4개)으로 데이트 코스 자동 생성
- 데이트 기록 자동화 (사진 + 장소 + 만족도)
- 과거 데이터 기반 추천 개선

---

## 4. ⭐ 핵심 가치 (Core Value)

- **빠른 결정** — 5초 안에 결정
- **반복 탈출** — 중복 방지
- **추억 관리** — 자동 기록
- **맞춤 추천** — 커플 데이터 기반

---

## 5. 🚀 핵심 기능 (MVP)

### 5.1 데이트 추천 시스템 (핵심)

**입력 (3~4개 선택)**

| 항목 | 옵션 |
| --- | --- |
| 오늘 상태 | 😊 / 😐 / 😵 |
| 분위기 | 🧘 / 🎉 / 🎯 |
| 활동성 | 🚶 / 🎡 |
| 예산 | 💸 / 💳 / 💰 |

**출력 (코스 형태)**

예시:

1. 브런치 카페
2. 산책 코스
3. 디저트 카페

> 👉 "장소"가 아니라 "흐름"을 제공

---

### 5.2 데이트 기록 (자동화)

- 사진 업로드 (1장)
- 장소 자동 저장
- 만족도 (⭐ 1~5)

> 👉 텍스트 입력 최소화

---

### 5.3 데이트 타임라인

- 날짜별 데이트 기록
- 사진 중심 UI
- 간단 회고 가능

---

### 5.4 추천 개선 로직

- 최근 데이트 유형 분석
- 만족도 기반 추천
- 중복 방지 (최근 N회 제외)
- "오랜만 추천"

---

## 6. 🔁 사용자 흐름 (User Flow)

### 1) 데이트 전

- 질문 선택 (5초)
- 추천 코스 확인

### 2) 데이트 중

- 사진 촬영 → 자동 기록

### 3) 데이트 후

- 만족도 선택

### 4) 이후

- 기록 축적 → 추천 고도화

---

## 7. 🧠 추천 로직 (간단 버전)

### 입력 기반 필터링

- 상태 + 분위기 + 활동성 + 예산

### 룰 기반 예시

- 피곤 + 조용 → 카페 중심
- 활동적 + 기분 좋음 → 액티비티

### 개인화

- 카페 비율 높으면 → 카페 추천 강화
- 최근 반복 유형 → 제외

---

